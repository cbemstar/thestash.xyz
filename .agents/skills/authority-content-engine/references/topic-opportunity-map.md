## Internal Linking Priorities

Link each new page to at least one page in each bucket:

- A sibling comparison page
- A relevant alternatives page
- A use-case collection or stack page
- A workflow or implementation guide

This structure reinforces semantic authority and helps crawlers understand topic depth.
