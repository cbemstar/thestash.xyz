# The Stash – Logo pack

Brand assets for **The Stash** (dev & design resources directory).

## Files

| File | Use |
|------|-----|
| `logo.svg` | Full wordmark “The Stash” – headers, print, social. Uses `currentColor` so it inherits text color. |
| `logo-icon.svg` | Icon only (stash/box) – favicons, app icons, small UI. |
| `logo-mark.svg` | Same icon at 48×48 – PWA, app icon, high-DPI. |

## Sizes & usage

- **Nav / header:** Use `logo.svg` or text “The Stash” (current app uses text in `AppNav`).
- **Favicon:** Use `logo-icon.svg` or export 32×32 PNG from it; Next.js uses `src/app/favicon.ico` by default.
- **Apple touch:** Export 180×180 from `logo-icon.svg` and add as `apple-touch-icon` in layout if needed.
- **OG / social:** Dynamic images are generated by `/api/og`; no static logo file required.

## Brand

- **Primary accent:** Orange/amber (e.g. `#f59e0b` → `#ea580c` in OG images; `primary` in Tailwind).
- **Wordmark:** “The Stash” – system font, bold, tight tracking.

All SVGs use `currentColor` so they work in light and dark themes.
