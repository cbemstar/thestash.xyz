# Using The Stash logos in Figma

All files in this folder are **SVGs** – drag and drop them into Figma for vector logos. You can scale them without quality loss.

## What’s in the pack

### Icon only (symbol)
| File | Use |
|------|-----|
| `icon.svg` | Dark icon – **light backgrounds** (white, light gray, cream) |
| `icon-white.svg` | White icon – **dark backgrounds** (navy, black, dark gray) |
| `icon-orange.svg` | Brand orange – **accent** (one-color hero, badges) |
| `icon-outline.svg` | Outline only – **subtle** or reversed (over photos, colored bg) |

### Wordmark only (“The Stash” text)
| File | Use |
|------|-----|
| `wordmark.svg` | Dark text – light backgrounds |
| `wordmark-white.svg` | White text – dark backgrounds |
| `wordmark-orange.svg` | Orange text – accent |
| `wordmark-stacked.svg` | “The” above “Stash”, dark – light backgrounds |
| `wordmark-stacked-white.svg` | Stacked, white – dark backgrounds |

### Lockups (icon + wordmark)
| File | Use |
|------|-----|
| `lockup-horizontal.svg` | Icon left, wordmark right, dark – light backgrounds |
| `lockup-horizontal-white.svg` | Same, white – dark backgrounds |
| `lockup-horizontal-orange.svg` | Same, orange – accent lockup |
| `lockup-stacked.svg` | Icon above wordmark, dark – light backgrounds |
| `lockup-stacked-white.svg` | Same, white – dark backgrounds |

### Legacy / web
- `logo.svg`, `logo-icon.svg`, `logo-mark.svg` – use `currentColor` for the live site; the variants above have fixed colors for design files.

## Tips for Figma

1. **Import:** Drag any `.svg` from this folder into a Figma frame, or use File → Place image and select the SVG.
2. **Brand font:** For pixel-perfect match to the site, install **Geist Sans** and, if you redraw the wordmark, use Geist Sans Bold (700) for “The Stash” and Semibold (600) for “The” in stacked versions.
3. **Resize:** Scale by dragging the corner; keep proportions (lock aspect ratio) so the logo doesn’t stretch.
4. **Colors:** To change colors in Figma, select the imported SVG → Ungroup (or detach) so you can edit fills. Or use the variants above (dark / white / orange) as-is.
5. **Spacing:** Don’t crop into the icon or wordmark. Keep a small clear space (e.g. height of the “T” in “The Stash”) around the logo.

Brand colors and gradients are listed in **brand-colors.md**.
