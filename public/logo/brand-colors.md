# The Stash – Brand Colors

Use these in Figma (or any design tool) for consistency with the site.

| Name        | Hex       | Use |
|------------|-----------|-----|
| **Primary** | `#f59e0b` | Orange/amber – CTAs, accent, icon accent |
| **Primary dark** | `#ea580c` | Darker orange – gradients, strokes |
| **Text dark** | `#171717` | Body and headings on light backgrounds |
| **Text light** | `#ffffff` | Text and icon on dark backgrounds |
| **Muted** | `#737373` | Secondary text, captions |
| **Background light** | `#fafafa` | Page/section background |
| **Background dark** | `#060010` | Dark UI (e.g. nav pill) |

Gradient (OG / hero): `#f59e0b` → `#ea580c` (left to right).

Font for wordmark: **Geist Sans** (Bold 700 for “The Stash”, Semibold 600 for “The” in stacked). Fallback in SVGs: system-ui.
