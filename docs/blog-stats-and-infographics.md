## Creating Custom Infographics

**Free tools:**
- **Icons8 Mega Creator** — https://icons8.com/make/infographic-maker
- **Visual Paradigm Online** — https://online.visual-paradigm.com/infoart/
- **Canva** — charts, diagrams, stat callouts
- **Freepik** — free tech/web infographic templates — https://www.freepik.com/free-photos-vectors/web-infographic

**Recommended visual types by data:**
- **Percentages** → Large callout, pie/donut
- **Year-over-year** → Bar comparison, line trend
- **Market share** → Pie chart, horizontal bar
- **Multi-metric** → Dashboard-style card grid
- **Rankings** → Ordered list with icons, ladder chart
- **Process/steps** → Flowchart, numbered steps

**Attribution:** When using data from these sources, add a clear citation (e.g., "Source: Stack Overflow Developer Survey 2024") and link to the original report.
